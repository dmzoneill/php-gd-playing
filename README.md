# php-gd-playing

Experiments with the PHP GD image library.

## Contents

- Scripts that draw text on images, centre text, render text with TrueType fonts
  and shadows, handle GIF transparency, draw bar graphs and convert hex colours.
- An Ajax page (`ajax.html`, `ajax.js` and the `ajax-*.php` scripts) that lets
  you choose a font, size, angle and coordinates and renders the image on the
  fly.
- `helloworld.php` and other small tests.

## Tech

- PHP with GD
- JavaScript (Ajax)

## Running

Serve the folder with PHP and the GD extension enabled. Some scripts use
hardcoded Windows (WAMP) font paths.
